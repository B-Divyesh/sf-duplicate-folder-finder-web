SAFETY MODEL

Proof before cleanup.

Mirrorbyte builds a fingerprint for every file, then rolls those fingerprints into each parent folder. A folder is called a duplicate only when the complete structure and contents match.

03 / QUARANTINE

Move reviewed copies?

Each folder will first be copied and re-hashed inside a timestamped .mirrorbyte-quarantine-… folder. Only verified originals are then removed.

    Reversible: restore a folder by moving it back in your operating system. Mirrorbyte never empties quarantine.
