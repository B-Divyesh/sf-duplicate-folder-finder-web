REVIEW HOLDING FOLDER

Move the reviewed copies to a holding folder?

Each folder is copied into a dated holding folder. Mirrorbyte checks the copy before removing the original.

    To restore a moved folder, move it back from the holding folder in your operating system. Mirrorbyte does not delete files from the holding folder.
